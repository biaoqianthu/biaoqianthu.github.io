# Biao Qian — Academic Homepage

Source code for [biaoqianthu.github.io](https://biaoqianthu.github.io), the personal academic homepage of Biao Qian.

The site presents research interests, education and experience, publications, invited talks, honors, and academic service. It is built with the [Academic Pages](https://academicpages.github.io/) Jekyll theme and deployed with GitHub Pages.
